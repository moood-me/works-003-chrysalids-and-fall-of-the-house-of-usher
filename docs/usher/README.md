# «Падение дома Ашеров» — документация игры

Игра по рассказу Эдгара Аллана По на мире «Падение дома Ашеров» (`moood-me/pavel--padenie-doma-asherov`):
тип bespoke, по образцу «Хризалид» (docs/khrizalidy/).

- [design.md](design.md) — замысел: что переживает читатель, лейтмотив и атмосфера, погружение (как
  привязать игрока к Родерику и Мэдлин), ход игры по главам с развилками, мини-игры, шкалы, финал и
  концовки, стилистика, как делаем.
- [scenes.md](scenes.md) — сцены мира и куски их фильмов: что видно, ключи состояния, элементы для выбора,
  реплики — контракт между сценами и кодом игры.
- [game.md](game.md) — что сделано и как устроено: где лежит, код игры, шкалы и что решает финал, как работать,
  что не доделано.
