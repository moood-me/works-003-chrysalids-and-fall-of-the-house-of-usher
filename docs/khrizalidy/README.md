# «Хризалиды» — документация игры

Игра по роману Джона Уиндема на мире «Хризалиды»: тип bespoke, код — в репозитории
`moood-me/pavel--game--khrizalidy` (`bespoke/`), сцены — в мире `pavel--khrizalidy-bespoke`.

- [design.md](design.md) — замысел (claude.ai): что переживает читатель, серые выборы, карта
  сценариев по главам, шкалы, концовки, сцены, предложения мини-игр. Игра идёт по нему.
- [bespoke-game.md](bespoke-game.md) — что сделано и как устроено: где лежит, API типа и кода игры,
  главы и ключи состояния, сцены и их состояния, как работать, что не доделано.
- [claude-ai-scene-author.md](claude-ai-scene-author.md) — письмо claude.ai, рисовавшего сцены: что ему
  нужно для работы (рендер, формат, анимация) и что из этого уже есть.
- [films-and-motion.md](films-and-motion.md) — сцены-фильмы, движок для них (плавность, таймлайн, камера,
  `place`, путь, `after`), модули мира и честные версии, модуль `chrysalids` (люди, кони, движения из
  записей живых людей), семь фильмов в мире «Хризалиды — кино», инструменты, что не доделано.
- [animation-review.md](animation-review.md) — ревью по 12 принципам Диснея, с которого начались фильмы.
- История дня: docs/history/2026-10-05-bespoke.md, moood-me/studio:docs/history/2026-10-05-film.md.
