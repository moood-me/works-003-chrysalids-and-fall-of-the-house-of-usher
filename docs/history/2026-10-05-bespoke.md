# 2026-10-05 — bespoke: игра, сделанная по мерке, и «Хризалиды»

Устройство — pavel-zhur/rpg:docs/architecture.md («Тип игры», «Движки»). Игра — репозиторий `pavel--game--khrizalidy`
(папка `bespoke/`), её мир — `pavel--khrizalidy-bespoke`.

## Запрос

Павел: отдельный локальный стек (`khrizalidy`, ветка `khrizalidy-gameplay`), чтобы делать геймплей
«Хризалид» по документу claude.ai «Хризалиды: переживания и серые выборы» (главы, развилки ⚑ и \~,
скрытые и видимые шкалы, метки людей, мини-механики, где действие и есть эмоция, схема ветвлений после
главы, как в Detroit). Тип игры — новый: «игра — это вся логика игры, весь код, снаружи сцен… связывает
бессвязный набор сцен мира в связную игру, управляет сценами, подключает ИИ по желанию». Имя выбирали
долго (code, plot, montage, crafted…) — остановились на **bespoke**: не формат, а вещь, сшитая по мерке.

## Решения

- **bespoke** (`engines/bespoke`, `web/site/bespoke`) — тип, который ничего не знает об игре. Её код —
  ES-модули в папке `bespoke/` репозитория игры (`game.js` и то, что он импортирует); страница партии
  импортирует `game.js` (по адресу `/api/bespoke/games/<id>/code/<версия>/…`) и даёт его default-экспорту
  API: сцены мира (показать, выставить состояние, плавно двигать значения, `where` — где элемент на
  экране), слой поверх сцены и свои стили, реплики голосами (`speech.js`), что игрок выбрал,
  сохранение партии (непрозрачный JSON игры). Движок хранит только партии и их сохранения.
- **Версии** — как у всех игр в git: партия держит версию игры, на которой началась; код отдаётся на
  этой версии (неизменяем — браузер держит его вечно). Партия автора идёт на игре как она есть сейчас:
  он её пробует. Код читается одним запросом к каталогу (`/api/games/<id>/folder/bespoke`) и
  держится в памяти по версии.
- **«Выбрать предмет → действие»** — механика рантайма сцены (`web/scene/actions.js`, доработки
  `select.js`), не игры: игра предлагает элементы и их действия; над выбираемым — рука, выбранный
  светится, действия открываются рядом. Павел: «теперь будет популярная штука… для всех интеракций,
  типа хождения по мирам». Всё, что игрок делает в «Хризалидах», идёт через неё, плюс мини-игры поверх.
- **Каркас игры — сцена.** Титул главы и схема ветвлений — служебная сцена мира «Нити» (ночное небо,
  нити выборов рисуются из её состояния; узел, который игрок выбирает, чтобы начать или идти дальше —
  он же первое касание, после которого странице разрешён звук).
- **Новые состояния сцен — правками, а не новыми сценами** (Павел: «пока не будем рисовать новые
  сцены»): телёнок и работник у инспектора (`calf_present`), оборачивающийся передний ряд на сожжении
  (`turned`), корабль, которым ведёт игра, во сне (`lead_x`, `lead_y`).
- **Для автора** (только его партия): ☰ — главы и шаги, перейти в любой; ⏭ — пропустить мини-игру,
  иначе шаг (брошенный шаг заглушается: ничего не показывает и не ждёт).

## Что сделано

- Пять глав: I «Шесть пальцев», II «Как положено» — я; III «Голоса», IV «Петра», V «Раскрытие» —
  агенты по одной главе, каждый со своей пробной игрой, общие файлы и движок — только через меня.
- Мини-игры (агенты): раскопки до колокола, найди раньше него, петь со всеми, не шелохнуться (I–II);
  ритм мехов, настройка, два слоя, успокоить, удержать сон (III–IV). Не сделаны: видение из дыма,
  соединить окна; в главе V — свои механики по таймингу без отдельных мини-игр.
- Голоса людей и мысленная речь («…» — Имя, шёпотом): озвученное хранится сервисом звука навсегда;
  197 реплик со стека khrizalidy перенесены в базы прода и локального стека main.

## Как переносили в main

Работа шла на отдельном стеке со своей базой (копия мира с прода), пока main переезжал в git. Потом
— отдельный worktree от main: в main только тип (движок, страница, механика выбора), переделанный под
репозитории игр (своя таблица кода ушла); игра — в свой репозиторий одной веткой и слиянием через
каталог; сцены — в новый мир «Хризалиды — bespoke» (копия «Хризалид» со всеми правками и «Нитями»),
созданный через API сцен на стеке main (прод взял его опросом). Ветка `khrizalidy-gameplay` слита с
main, папка `games/` из неё ушла.

## На чём споткнулись

- **Перегрузка машины** тремя агентами с тестами в программном рендере: контейнеры не проходили
  проверки здоровья, Traefik снимал маршруты — 404 посреди игры. Агенты по одному, браузер по одному.
- **Лимит озвучки Gemini** кончился на прогревах реплик (около суток до сброса): реплики глав III–V
  и мини-игр пока без голоса.
- **Тест «находит» выбираемое медленнее игрока**: окна по времени (копыта, всадник) в тестах «не
  успевали» — время судим по коду, тест подменял `select.js`, чтобы искать мгновенно.
- **Выкладка из рабочей папки** однажды унесла в игру незаконченные правки агентов — с тех пор только
  из коммита.
